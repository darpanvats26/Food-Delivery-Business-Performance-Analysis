# Food-Delivery-Business-Performance-Analysis

## Overview

This project performs Exploratory Data Analysis and data visualization on a Food Delivery Business Performance dataset using Python.

The objective is to identify meaningful patterns in orders, revenue, marketing spend, delivery performance, customer ratings, cities, cuisines, weather conditions, and order channels.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Visualizations

The notebook contains:

- Line plots
- Bar charts
- Scatter plots
- Histograms
- Box plots
- Violin plots
- Count plots
- Correlation heatmap

## Key Analysis Areas

- Monthly orders and revenue trends
- City-wise performance
- Cuisine-wise performance
- Marketing spend vs revenue
- Delivery time vs customer rating
- Weather and delivery performance
- Order channel performance
- Correlation between numerical variables

## Files

- `Day14_Food_Delivery_Visualization_Portfolio.ipynb`
- `Day14_Food_Delivery_Visualization_Dataset.csv`

## Conclusion

The analysis shows that business performance is influenced by multiple factors. Delivery time has an important relationship with customer satisfaction, while city, cuisine, order volume, average order value, weather, and marketing activity also contribute to overall performance.
